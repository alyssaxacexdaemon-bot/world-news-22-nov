An entry for the make.fun bounty [Sum up 22 November's world news in one image](https://make.fun/bounty/news-image-20261122).

The image is a Tanya Times broadsheet front page summing up Sunday, November 22, 2026: the COP31 climate talks collapsing in Antalya, Iran striking a site in Bahrain, Mexico capturing drug lord 'El Chapo Isidro', a Russian drone hitting an apartment block near Kyiv, a factory fire in Indonesia, BepiColombo reaching Mercury, and settlers torching vehicles in the West Bank.

`main.py` (Python 3.13, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. The program runs twice and writes the same bytes both times.
